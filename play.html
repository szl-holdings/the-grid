Controls and exhibit limits

Move with W A S D, change tool with Q / E, scan with R, hold F to extract, and hold Space to overclock. C starts Convergence early. Focus the lattice to use keyboard controls; Esc pauses. On-screen controls support touch or keyboard.

Collect at least 20 juice, select EXTRACTOR and reach an open gold window to extract. The run pauses when this tab loses focus. Best score and run count are stored only in this browser when storage is available.

The lattice is a visual canvas; the text HUD and controls do not provide a complete nonvisual version of the game. Original Vite src/game never landed in this tree. This file is the playable source of record.
